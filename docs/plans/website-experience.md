# Website: homepage and Recorded Lab as one visitor journey — plan and status

Status 2026-10-13: implemented on a private branch; not published.

## Goal

A visitor who does not know ROS 2 should learn what RobotOps is, see what the
Warehouse Navigation Benchmark v1 showed (and did not show), then watch and check the
recorded trials themselves. No new evidence, metrics or experiments; the public
site stays static and read-only.

## Structure

Shared: `web/src/site/` holds the header, footer, release wording (`release.ts`),
the benchmark disclosures (`BenchmarkCautions.tsx`, used on both pages) and a
dot-per-trial chart (`StripChart.tsx`). Both pages use the same tokens in `site.css`.

Homepage (`web/src/portfolio/`): hero with the recorded W01 route over the
warehouse layout → what RobotOps does → where it fits beside Gazebo, Nav2, RViz and
Foxglove → benchmark v1 results with every disclosure → robotics and software work
→ engineering challenges → architecture → lab invitation → project status.

Recorded Lab (`web/src/replay/`): introduction with a five-step journey —
1 the experiment (with disclosures), 2 results (outcome counts, configuration
summaries, findings, six-trial table with Replay buttons), 3 watch the robot
(player, map, 3D, LiDAR), 4 compare configurations (charts, summary, conditions),
5 inspect the evidence (original outcome beside visitor checks, technical detail
in expandable sections) — then the separate earlier baselines N0/N2.

## Where displayed numbers come from

- Lab: computed in the browser from the six hash-pinned manifests. A finding
  ("finished every trial sooner") is shown only when every trial supports it.
- Homepage: constants in `portfolio/benchmark.ts`, copied from the reports; the
  route in `portfolio/w01-route.ts` is generated by `web/scripts/homepage-route.mjs`.
  Tests re-derive both from the pinned datasets when they are present.

## Default selection

The lab always opens on W01 and stores no selection (no storage, URL or history
state); a test guards this. A preview found open on N2 was a browser tab left on
N2 by an automated check that steps through all eight recordings.
